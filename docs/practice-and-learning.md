# 新手學習、模擬投資與配置 v1

產品流程為：目標式研究首頁 → 新手名詞／任務 → 個股研究 → 虛擬買賣 → 理由與情緒 → 覆盤／持股配置。提醒通知仍跳過，沒有新增背景輪詢、行情快取或自動重試。

## 模擬帳戶語意

`app.paper_accounts` 保存使用者的帳戶名稱、起始虛擬資金、自行指定的練習交易、理由、心情、覆盤與版本。此資料與 `workspace_items` 中的真實手動投資帳本分開。保存的 price 是使用者確認的練習交易成本，不是報價快取；不保存歷史來源回應、價格序列、持股市值或配置圖結果。`market` schema 維持無表。

每人最多 5 戶；每戶最多 500 筆、10 檔 TWSE 代碼。價格、費稅使用 Decimal，股數為正整數；起始資金大於零且最多 10 億元。只提供多頭現金練習，不能透支或超賣，日期不得早於前一筆。日期相同依新增順序計算，不把事後插入的交易改排到前面。移動平均成本含買進費稅；賣出費稅扣除已實現損益。

這是指定價格的模擬記帳，不是券商撮合或可投資績效。來源參考使用原始未還原收盤，沒有排隊、滑價、漲跌停、交割延遲或券商費率模型。費稅由使用者填寫，預設 0 只是練習假設。v1 不自動入帳股利或調整分割，跨公司事件時不可將顯示損益當作完整績效。

## 私人 API

以下均需 Cookie session，owner 固定取登入身分，不接受 user_id。回應 no-store。所有寫入沿用 Origin／JSON／CSRF 檢查，實際 body 上限 16 KiB。

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| GET / POST | `/api/v1/practice/accounts` | 本人帳戶／建立 `{name, initial_cash}` |
| POST | `/api/v1/practice/accounts/{id}/orders` | `{version, order}`，確認新增一筆練習交易 |
| PUT | `/api/v1/practice/accounts/{id}/orders/{order_id}/reflection` | `{version, reflection}`，只修改事後覆盤 |
| DELETE | `/api/v1/practice/accounts/{id}?version=...` | 明確刪除整戶及日誌 |
| GET | `/api/v1/practice/accounts/{id}/valuation` | 手動取得本次持股估值、現金與估計總資產 |
| GET | `/api/v1/practice/reference?code=2330&day=YYYY-MM-DD` | 目前上市標的指定日的歷史收盤參考 |
| GET | `/api/v1/practice/progress` | 本人四項任務的衍生完成狀態 |

order 包含 UUID、buy／sell、TWSE 代碼、日期、整數 quantity、Decimal price／fees／taxes、reason、emotion。理由不可空白；emotion 為 calm／optimistic／anxious／fomo／uncertain。首筆提交不能夾帶覆盤，之後再自行補寫。成交欄位不可改寫，避免事後修改模擬結果。需要其他情境可另開帳戶。

鎖順序為 user → account。版本不符回傳 409；前端保留輸入，重新載入後再檢查。交易 UUID 是帳戶內的冪等識別；重送相同交易回傳目前帳戶，不扣第二次現金。相同 UUID 改變成交內容回傳 409。覆盤可獨立更新，不使相同交易重送變成重複成交。外人讀寫回傳 404，硬刪帳號由 FK 一併刪除模擬資料。

歷史參考先向 TWSE 驗證目前上市代碼，再向免費 FinMind 取指定日原始價；缺價或非交易日回傳明確錯誤，沒有沿用前日、舊結果或補零。讀參考不會自動下單，使用者需確認指定練習價後才記帳。估值依序取得名錄與各持股來源，之後再核對帳戶版本；結果不寫資料庫。

## 五面向研究與資產配置

既有真實帳本與新模擬帳戶共用估值與配置計算。配置只包含仍持有證券的市值，不含現金；模擬總資產另加虛擬現金。所有持股皆有有效估值才回傳個股／產業百分比，部分缺價時不將缺值當零，不繪製完整配置。零持股明確為 empty。產業缺值分為「產業未確認」，分類是最新參考名錄，非歷史產業身分。

圖表使用近似浮點值繪製，明細保留 Decimal 計算的金額及四位小數百分比；四捨五入可能使占比合計略有差異。單一分類達 50% 時只提示回顧集中配置，不做買賣建議。既有財務健檢仍是成長、獲利、財務結構、現金流及股利的白話摘要，沒有新增黑箱分數或未定義的 ROE 公式。

## 新手任務

進度由本人實際資料衍生：至少一檔觀察、至少一份研究筆記、至少一筆模擬買進、至少一筆非空覆盤。訪客可閱讀全部名詞與任務，但不查私人進度。完成狀態不是學會投資的證明；刪除相應資料後可回到未完成。只在進入或手動更新時查詢，不設背景追蹤。

## Migration 與驗證

新增 migration `0007_paper_accounts`，只建立私人資料表與索引，不改寫既有帳本或使用者資料。更新應用前執行 `uv run alembic upgrade head`，或使用既有 Compose 的啟動 migration 流程。降版會移除此新表，已有練習資料時請先備份。

測試使用專用 PostgreSQL，瀏覽器驗證另用第二個隔離資料庫；不連既有使用者資料庫。自動測試涵蓋精確費稅／成本、透支／超賣／日期拒絕、冪等與併發、本人授權、CSRF／body 限制、外人404、私人狀態失效及缺價配置語意。真實來源只用手動獨立驗證，不放進測試固定資料或資料庫。
