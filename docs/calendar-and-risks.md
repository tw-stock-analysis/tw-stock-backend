# 除權息、交易日曆與官方風險公告

這組公開功能使用既有 TWSE adapter，維持逐次請求、不重試、不快取、不入庫；不新增資料表或 migration。只彙整來源本次發布的公告，不能用日期篩選向 TWSE 查詢任意歷史資料。

| GET 端點 | 功能 | 依序取得的來源 |
| --- | --- | --- |
| `/api/v1/research/calendar` | 除權息、開休市事項篩選及分頁 | `TWT48U_ALL` → `holidaySchedule` |
| `/api/v1/research/calendar/export` | 重新取得完整篩選結果，下載 ICS | 與日曆查詢相同 |
| `/api/v1/research/risks` | 注意、處置、暫停交易公告 | `notice` → `punish` → `TWTAWU` |

在 `app/api/v1/endpoints/research.py` 明確宣告路由，輸入輸出模型位於 `app/schemas/notices.py`，服務位於 `app/services/notices.py`。每份來源最多等候 15 秒，三份依序取得最多 45 秒，低於既有 Nginx 60 秒上限。取消會向外傳遞，不重試已失敗來源。

## 日曆條件與日期

`kind=all|ex_dividend|market` 決定要取得的來源，預設 `all`。`q` 搜尋代碼、名稱或事項說明（最多 100 字）；`from_date`／`to_date` 為 `YYYY-MM-DD`，範圍含起迄日。`page` 預設 1，`limit` 預設 20、最多 100。先對完整當次結果篩選及排序，再分頁；只選一種事件時只請求該來源。

官方民國或西元日期轉換成無時區的 ISO 日期，同時保留 `source_date` 與所有 `fields` 原始欄位。無法辨識的日期傳回 `date=null`；未指定日期區間時仍可在列表最後查看，指定日期區間時排除。`undated` 是符合文字條件但日期無法辨識的數量，讓使用者知道日期篩選或匯出可能排除哪些資料。

開休市來源也包含開始交易、最後交易、無交易等事項，不將所有事件標為休市，也不依週末或未列出的日期推定市場狀態。官方說明中的 HTML 轉為純文字摘要；原始欄位仍完整保留，前端以文字顯示。

## ICS 下載

匯出忽略 `page`／`limit`，重新取得完整篩選結果。所選來源必須全部成功，否則回 503 `SOURCE_INCOMPLETE`，不產生可能缺漏的檔案。日期不明事件不匯出，透過 `X-Skipped-Undated` 回報排除數量。回應為 `text/calendar`，檔名 `twse-calendar.ics`，可匯入一般日曆工具。

使用 RFC 5545 全日事件，`DTSTART;VALUE=DATE` 是事件當日，`DTEND` 是下一日（不含），`TRANSP:TRANSPARENT` 不占用忙碌時段。UID 以來源、日期及事件身分產生；UTF-8 行折疊不超過 75 octets，處理換行、逗號、分號及反斜線跳脫。這是單次公告快照，匯入後不會自動訂閱或更新；後續異動需重新確認官方公告。

## 風險公告

`kind=all|attention|disposition|suspension` 決定來源，`code` 可選、必須是 4～6 位大寫英數代碼，以字串精確比對，保留前導零；不額外查詢日成交資料，因此不會因標的暫停交易而無法檢索公告。`page`／`limit` 與日曆相同。

`announced_on` 只使用官方 `Date`，不以取得時間或暫停日期補成公告日期。處置起迄期間、條件、措施、暫停及恢復交易日期時間均保留在 `fields`，摘要加上欄位標籤；完整處置內容可從原始欄位展開查看。不根據這些可能包含歷史內容的快照推斷目前生效狀態，不計算風險分數。

2026-10-23 實測注意股票來源會以單筆 `Number="0"`、代碼／名稱／日期／注意文字均空白、次數／收盤價／本益比為空白或零表示無公告。服務只在欄位集合及整筆內容完全符合此格式時轉成成功的 0 筆公告；其他缺身分或不完整資料仍標為來源異常。原始 44 個 TWSE 直通端點不改寫此回應。

## 成功、空資料與失敗

`sources` 各自提供名稱、來源 URL、取得時間、成功／失敗、已辨識事件／公告數 `row_count` 及失敗訊息。成功的空資料／官方空標記是 `status=ok,row_count=0`。同一來源重複的完全相同事件去重；缺身分或衝突的事件不會混入成功結果。

部分來源失敗時只傳回本輪成功取得的結果，`complete=false`，不沿用上一輪內容。所選來源全部失敗則回 503。`complete=true` 僅表示所選來源均成功取得，不表示所有市場風險已被涵蓋；沒有符合公告不代表無其他風險或必然可交易。

## 前端及驗證

`/research/calendar` 提供條件、未來 30 天（臺北今日起算）、列表、分頁及 ICS 下載；`/research/risks` 提供代碼及公告類別查詢。條件保存在 URL，輸入時不自動查詢。個股頁按「取得此股風險公告」才依序取得三份來源，離開或更新個股會中止並清除結果；也可進入該股的完整公告頁。

`tests/test_notices.py` 使用合成資料驗證日期、空標記、參數驗證、逐次來源、部分失敗／逾時、完整匯出與 ICS 跳脫，禁止使用 DB session。前端 `tests/notices.test.tsx` 驗證篩選、URL、下載、資料清除及取消。另以 Chromium → Vite → FastAPI → 真實 TWSE 驗證桌面與手機，ICS 由獨立 `icalendar 6.3.1` 解析器讀取；驗證資料僅保存結果與來源筆數，不保存行情或完整公告，見 [驗證紀錄](notices-verification.json)。
