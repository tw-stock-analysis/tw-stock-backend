# FinMind 個股歷史研究

新增 `GET /api/v1/stocks/{code}/analysis`，對應前端 `/stocks/:code/history`。

## 設定與驗證

後端 `.env` 或執行環境 Secret 設定 `FINMIND_API_TOKEN`。空值使用匿名免費額度；有效 Token 使用會員額度。Token 僅以 Bearer Header 傳給固定主機，不放入 URL、JSON 回應或前端。Compose 既有後端 `env_file` 會載入此設定，無須改資料表或加前端金鑰。

執行環境須允許 `api.finmindtrade.com`。這輪未加入會員用量查詢，不會請求 `api.web.finmindtrade.com`。來源封鎖或無權限直接顯示錯誤，不繞過代理。

只讀驗證，不開資料庫連線、不寫行情檔案：

```bash
UV_CACHE_DIR=/tmp/twstock-uv uv run python -m app.services.finmind_check --code 2330
UV_CACHE_DIR=/tmp/twstock-uv uv run python -m app.services.finmind_check --code 0050 --start-date 2026-07-01 --end-date 2026-07-31
```

輸出只有區塊狀態、筆數、時間與錯誤代碼。三區塊成功（包含合法空資料）才回 exit 0。

`UV_CACHE_DIR` 僅指定 uv 的套件下載／建置快取，與行情資料無關。受限執行沙箱須開啟該次指令的網路權限；保留環境的 HTTPS proxy 與 TLS 驗證。網域列在設定中不代表連線已可用，應以上述實際請求確認。

## 契約與資料流程

- 先用 TWSE 最新日成交清單確認代碼，保留目前只支援現行上市標的的邊界。找不到回 `STOCK_NOT_FOUND`，不請求 FinMind。
- `end_date` 預設台北今天，`start_date` 預設截止前 180 天；不得早於 1994-10-01、開始晚於截止、截止為未來或顯示區間超過 366 天。未知參數與無效日期在呼叫來源前回 422。
- 身分確認後，依序請求 `TaiwanStockPrice`、`TaiwanStockMonthRevenue`、`TaiwanStockInstitutionalInvestorsBuySell`。不提供自由 URL 或任意 dataset 代理。
- 每次重查均為新請求；同一 worker 內的 FinMind HTTP 請求以 lock 逐次執行。不同 worker 不共用 lock，部署容量仍依 Token 額度規劃。
- JSON 數值精確解析為 Decimal／字串，圖形才轉近似值。限制 8 MiB、15,000 列及欄位／數字長度，檢查重複、代碼、日期與必要欄位。
- 不使用行情資料庫、跨請求快取、本機行情檔、自動重試或輪詢。回應為 `Cache-Control: no-store`。

回應含 `code`、`name`、`market`、查詢區間、`identity_source`、`complete` 與三個資料區塊。區塊均有 `status`／`data`／`meta`／`error`：

| status | 含義 |
|---|---|
| `ok` | 成功；空陣列表示來源沒有資料 |
| `error` | 本次曾查詢但失敗，data 為 null |
| `not_requested` | 前一資料集已發生來源存取問題，本次未繼續查詢，附上原因 |

格式問題只影響該區塊，仍取得其餘資料。HTTP／JSON 401、403、402、429 與網路／服務故障會停止後續 FinMind 呼叫。錯誤使用固定 `FINMIND_*` 代碼與訊息，不回傳來源錯誤正文或憑證。

`meta` 含來源、dataset、來源實際查詢區間、取得時間、來源列數與單位。列數包含計算暖機資料，不等於畫面筆數。

## 計算方式

**日線**：向前最多 180 個日曆天作暖機（不早於來源起點）。依日期排序，用最近 20／60 筆來源收盤價計算簡單平均；不足回 null，四捨五入至四位小數。停牌／新上市可能仍無足夠資料。價格未還原，價與成交額為新台幣元、日成交量為股。

日線另含 `rsi14`、`macd`、`macd_signal`、`macd_histogram`、`bollinger_middle`、`bollinger_upper`、`bollinger_lower`。所有指標在後端以 Decimal 計算，僅在輸出時四捨五入到四位小數，前端切換指標不增加 API 請求。

| 指標 | 定義與暖機 |
|---|---|
| RSI14 | 先用 14 個有效收盤價變動的平均漲／跌額初始化，再以 Wilder `(前值 × 13 + 本期變動) / 14` 平滑。第 15 筆有效收盤價起有值。全平為 50、只有上漲為 100、只有下跌為 0。 |
| MACD | EMA12 − EMA26；EMA 以首 12／26 筆簡單平均初始化，後續權重為 `2 / (期數 + 1)`。第 26 筆起有值。 |
| 訊號線／柱狀值 | 訊號線為 MACD 的 EMA9，同樣以首 9 筆 MACD 平均初始化；第 34 筆有效收盤價起有值。柱狀值為 MACD − 訊號線，未乘二。 |
| 布林通道 | 中軌為 MA20，上下軌為中軌加減 2 倍最近 20 筆收盤價的母體標準差；第 20 筆起有值。 |

EMA 與 RSI 會受本次有限暖機範圍影響，可能與使用更長歷史或不同初始化方式的看盤軟體不同。未還原股價在除權息、分割時也會影響指標；這些值不作為自動買賣訊號。

指標數值、營收完整月份邊界，以及 `2330`、ETF、`2317` 真實無公告成交價的驗證紀錄見 [第一階段驗證](finmind-indicators-verification.json)。

現行上市標的也可能有上市前紀錄。開盤欄超出高低範圍時保留數值，標記 `opening_reference`，圖中只畫高低與收盤；興櫃開盤欄可能代表前日均價。高低顛倒或收盤超出範圍則視為格式問題。

來源開高低收全為零時，代表該日無公告成交價，回 `price_available=false`。API 保留原始零值、成交量與金額，該日 MA／RSI／MACD／布林皆為 null；指標只使用有公告收盤價的序列，不補價、不把零當收盤價。前端不畫該日 K 棒，價格明細顯示 —，成交量仍保留；後續有效日接續先前有效收盤序列計算。

**營收**：同一次請求取得截止前 60 個月份供比較，顯示截止月份往前最多 36 個月。較早的暖機月份用於最早可見月份的去年累計與前期 12 個月比較，不增加資料集請求次數。使用 `revenue_year`／`revenue_month` 建立營收月份，金額為新台幣元。YoY／MoM 比較前 12／1 個月；缺少比較月份或基準不大於零時回 null，零營收本身保留為零。`record_date` 沿用來源 date，`recorded_at` 保留可用的 create_time；兩者不推定為正式公告時間。

每個營收月份另含 `ytd_revenue`（當年 1 月至該月合計）、`ytd_yoy`（去年相同月份區間的年增率）、`trailing12_revenue`（含該月的連續 12 個月合計）、`trailing12_yoy`（與前一組 12 個月比較的年增率）。合計所需月份不全回 null，不補零；成長率須兩組月份皆齊全且前期合計大於零。合計保留精確整數字串，成長率四捨五入到四位小數。前端卡片標示本次最後一個營收月份，圖表可切換單月、年初累計與近 12 個月營收，明細保留全部指標。

**法人**：向前最多 90 個日曆天作累計暖機。買進、賣出與差額為股，各來源分類分開顯示，保留未知新分類，不將外資自營或自營商分項重複加總。`net5`／`net20` 使用含當天的最近 5／20 個來源有資料的日期；分類缺漏或筆數不足回 null，不補零，不保證上游完全沒有漏日。

## 前端與驗證範圍

個股摘要提供歷史研究連結。進頁、送出日期或手動重查只發一個站內請求；日期保留於 URL，瀏覽器不直接連 FinMind。提供日 K／成交量／均線、月營收與法人圖表，各有精確明細、來源及台北取得時間。切換法人分類只改本次視圖；更新中隱藏舊圖，失敗不沿用舊值。未新增 FinMind 原始資料下載／匯出。

自動化測試使用合成資料，不作產品行情。2026-10-24（台北）已透過既有 HTTPS proxy 完成匿名真實來源驗證，未設定會員 Token。指定的 `2330` 預設指令三區塊均成功，顯示日線 123 筆、營收 35 筆、法人 123 筆；`0050` 與 `00981A` 的 2026 年 7 月日線／法人各 22 筆，ETF 營收為合法空陣列。筆數只代表本次觀測，之後查詢可能不同。

真實 FastAPI 路由另驗證重查均重新依序呼叫 TWSE 與三個 FinMind 資料集、週末空資料、`0050` 分割期間、未知代碼與無效參數。來源最大同時請求數為 1；此組驗證未建立資料庫 engine，資料庫 session dependency 也設為呼叫即失敗。回應均為 `no-store`，紀錄只保存狀態、筆數及時間等驗證資訊，不保存行情列。詳見 [驗證紀錄](finmind-verification.json)。

前端以 Chromium 經本機 Vite proxy 與 FastAPI 連到真實來源，桌面驗證三圖、手動重查、法人本機切換、週末與 ETF 空營收；390px 手機驗證 `00981A`、精確明細、無水平溢出及無效日期後移除舊圖。瀏覽器沒有直接請求 FinMind，沒有 JavaScript 錯誤。此次未發現須修改解析或圖表程式的問題；已更新過期的網路封鎖與待驗證說明。會員 Token、真實額度耗盡及正式部署拓樸不在本次真實驗證範圍；來源權限與額度錯誤流程由合成測試覆蓋。
