# 台股資料、計算與品質規格

本文件保存在後端專案，作為資料接入與計算功能的實作依據。

研究日期：2026-10-16。以下區分官方資料集已描述的能力與尚待實際介接驗證的能力。此輪未下載完整歷史行情、沒有取得商業資料授權，也沒有執行同步。

## 1. 第一版資料範圍

上市／上櫃普通股、收盤後日資料、最新可知基本面及歷史數值趨勢。日價量目標兩年、月營收三年、財報十二季，為產品目標而非已驗證的來源覆蓋。第一階段以代表性樣本完成端點、欄位、歷史範圍、雲端連通性與使用條件驗證。

官方資料入口通常依資料類型各自提供；「有 OpenAPI」不表示同時有即時行情、任意日期查詢或完整歷史財報。官網公開頁面也不自動代表能無限制重發所有內容。

## 2. 官方來源證據

| 類型 | 本次確認 | 尚待實作驗證 |
| --- | --- | --- |
| 上市日價量 | [上市個股日成交資訊](https://data.gov.tw/dataset/11549) 列出日期、代號、OHLC、股數、金額、筆數及開放授權 | 實際資料取樣、歷史回補入口、欄位型別、成交統計範圍 |
| 上櫃日價量 | [上櫃股票行情](https://data.gov.tw/dataset/11370) 描述價量欄位，資料範圍含其他商品 | 普通股分類、歷史範圍及目前可用端點；不能把每列當普通股 |
| 上市月營收 | [上市公司每月營業收入彙總表](https://data.gov.tw/dataset/18420) 描述月營收與去年同期等欄位 | 舊月份下載、各公司原始公告時間；出表日期不等於公司公告日 |
| 上櫃月營收 | [TPEx OpenAPI](https://www.tpex.org.tw/openapi/) 為官方介面入口 | 本次讀取規格遇到 403；端點、欄位、歷史覆蓋與環境可用性列待驗證 |
| 財報 | [公開資訊觀測站](https://mops.twse.com.tw/mops/web/t120sb02_q10) 提供財報／XBRL／公告與更正相關入口 | 穩定結構化下載、合併／個別、產業模板、修訂與公告時間 |
| 官方估值 | [TWSE 本益比等計算說明](https://www.twse.com.tw/zh/trading/historical/bwibbu.html) 說明其盈餘與股數基礎，不能假定等同簡單 EPS 除法 | 取樣 PE／PB／殖利率端點、歷史及口徑版本 |
| 企業行動 | [上櫃除權除息計算結果](https://data.gov.tw/dataset/11633) 有除權息日、參考價及相關欄位 | 全市場涵蓋、減資／拆併股等其他事件；此資料不等於完整復權資料集 |

[TWSE OpenAPI](https://openapi.twse.com.tw/) 與 [TWSE Swagger](https://openapi.twse.com.tw/v1/swagger.json) 作端點探索入口。各 adapter 採已實測規格，不在本規劃猜測路徑參數或供應商配額。TPEx 的單次 403 不能推論所有雲端 IP 永遠不可用，也不採繞過存取限制的做法。

每個資料集記錄 source_url、license_url、允許的使用範圍、署名與查閱日期；上述已登錄政府開放授權的資料依個別條款保留來源。[政府資料開放授權條款](https://data.gov.tw/license)。若官方來源不能支持目標歷史，保留相同 adapter 介面，後續選擇合適供應者或縮小可用範圍，不先承諾完整資料。

## 3. 識別、單位與交易日

公司 issuer 與可交易證券 instrument 分開。股票代碼採字串，穩定 UUID 作內部 ID；listing 保存市場、代碼及有效期間，轉板／下市不抹除歷史。

日資料定義為來源的官方日成交彙總，price_scope 要記錄具體包含的交易範圍；不是看到 close 就假設等於某種盤中最後一筆。原始單位在 adapter 中核對：股、張、元、千元、百分比不得直接混用。民國日期只在 adapter 轉為 ISO，原始字串留在證據中。

休市使用市場日曆，包含臨時休市修訂。休市不產生 K 棒；停牌／明確無成交留狀態，不造 OHLC；來源原因不明的缺口列品質問題。技術指標用有效成交觀測，不把週末或缺值當零；原因不明缺口影響的計算區間不發布，直到修復或明確標為不可用。

報價漲跌需標明基準：官方漲跌可能以參考價為基準，原始收盤較昨日收盤的變化是另一個指標。尤其除權息日不可把兩者混為同一欄位。

## 4. 時間與版本

| 欄位 | 意義 |
| --- | --- |
| trade_date／period_end | 行情交易日／財報所描述期間 |
| published_at | 可驗證的來源公告時間，未知則 NULL |
| first_seen_at | 本系統首次看見此版本 |
| source_available_at | 可推導的保守公開可用時間；若只有日期，採下一交易日開始；未知則 NULL |
| available_at | 本產品發布且可用時間，不早於 first_seen_at 與已知的 source_available_at |
| revision／data_version | 來源修訂與產品發布版本 |

財報期間結束不等於公告時間；出表日期不等於各公司公告日。回補今天才看到的舊資料不能偽造成本系統早已知道。第一版提供歷史數值趨勢，不提供「當時已知資訊」回測；要做回測必須另驗證歷史公告、版本、下市與企業行動完整性。

財報更正追加版本。當前趨勢採最新有效且口徑一致的版本；可看版本與來源。不能把最新修訂值安插到過去時點後宣稱沒有前視偏誤。

## 5. 價格與企業行動

第一版 price_basis=raw，即未還原價，圖表與指標一致標示。官方事件可作圖上標記；資料未涵蓋不假造事件。

未來加入復權時需固定基準日、因子來源、事件種類及算法版本；原始價格永遠保留。除權息、減資、拆併股分別處理，價格還原與含股利再投入的總報酬分開。現金股利不可機械地反向調整成交量。公司行動修訂會使受影響價格及指標重算並改版。

## 6. 技術指標精確定義

以下是本產品的算法規格；不同看盤軟體的初始化與顯示可能不同，不能只以外觀相似當驗收。

| 指標 | 算法與邊界 |
| --- | --- |
| MA(n) | 最近 n 筆有效收盤價算術平均；preset 5/20/60/120；不足 n 筆為 NULL |
| EMA(n) | α=2/(n+1)，第一個值用最初 n 筆 SMA，之後 EMA=α×當期收盤+(1−α)×前期 EMA |
| RSI(14) | 先用14個價差計算平均漲／跌，後續 Wilder 平滑：(前均值×13+當期值)/14；需15筆價格；RSI=100−100/(1+平均漲/平均跌)；只漲100、只跌0、全平50 |
| MACD(12,26,9) | DIF=EMA12−EMA26；Signal 為有效 DIF 的 EMA9（先以9筆 SMA 起始）；Histogram=DIF−Signal，不乘2；Signal 暖機不足時 Signal/Histogram 為 NULL |
| Bollinger(20,2) | 中線 SMA20，上下線=中線±2×最近20筆收盤的母體標準差，ddof=0；不足20筆 NULL |

遞迴指標不能依使用者每次選的可視起點重新 seed。每檔以固定且記錄的歷史起點計算／保存 seed，回應含 seed_date、input_version 與 algorithm_version；使用者改 3M/1Y 僅裁切輸出。新增更早歷史或修訂價格時重算並改版，明確解釋數值變化。

初始可用歷史有限時，以實際最早可靠資料 seed 並回傳覆蓋；不聲稱與從上市首日計算完全相同。明確停牌可跳過成交觀測；未知資料缺口則不悄悄跨過。單位測試固定有效樣本、seed、容差與預期數值，不只比較兩套相同實作。

## 7. 基本面定義

| 指標 | 規格 |
| --- | --- |
| 月營收 | 保存來源原單位並正規化成元；來源的單月與累計欄位分開 |
| YoY | (本月/去年同月−1)×100%；基期缺值或<=0 時 NULL＋原因 |
| MoM | (本月/上月−1)×100%；同樣檢查基期 |
| EPS | 保留官方基本／稀釋、單季／累計、合併／個別標記；無獨立單季值時明示不能推導 |
| TTM EPS | 僅在四個可比較單季 EPS、股本基準與資本變動處理可確認時相加；否則 NULL |
| 官方 PE/PB/殖利率 | 優先展示來源發布值及其口徑；不以自行計算值冒充官方值 |
| computed_pe_ttm（後續） | 未還原收盤/相容基準 TTM EPS；EPS<=0 或不可比較時 NULL；method 與官方分開 |
| ROE TTM | 四季歸屬母公司淨利總和 / [(本季末母公司權益+四季前季末母公司權益)/2] ×100%；缺值或兩個權益任一非正時不輸出一般 ROE |
| 毛利率／營益率 | 使用同期間、同口徑金額除以營收；產業不適用時標示不適用；金融業不硬套一般工業科目 |

同年度、相同口徑及一致修訂基礎下，損益「金額」可由累計值相減推單季：Q2=H1−Q1、Q3=9M−H1、Q4=FY−9M。資產負債表是時點數，不能相減當季值；EPS 的加權平均股數會變，累計 EPS 也不能一律直接相減。比率不能直接相減。

財務計算 Decimal 處理，展示時才依欄位規則四捨五入。負營收／極端值先標品質與口徑，不直接全部丟掉；虧損 EPS 是有效負數，PE 不適用是另一個狀態。

## 8. 同步與發布

流程：排程 → 來源 adapter → 原始證據 → staging 正規化 → 品質檢查 → 短交易發布 → 指標重算／快取改版 → API 可讀。

起始排程可設每日台北時間18:00及21:00嘗試更新日資料，這只是產品預設，不是交易所公布時間承諾。月營收／財報可每日檢查變更及更正；不能只在季末抓一次。HTTP 200 不代表新交易日已更新，以資料日期、內容 hash 與完整性判斷。

單一來源低並發，設定 timeout、重試上限與退避；遵守 Retry-After，未確認配額不宣稱無限制。相同範圍重跑冪等，失敗不覆蓋前次有效版。來源連線在本機及目標部署環境各測一次。

freshness 判斷看交易日曆與來源的更新寬限，不單純將今日日期與資料日相比。休市顯示上一交易日仍可 current；盤後等待來源可 pending_update；超過已設定寬限才 stale；日曆／更新規律未確認則 unknown。

## 9. 資料驗收

- 日資料無重複主鍵；OHLC 合理、量非負，缺值文字不轉零。
- 上市／上櫃各取樣，涵蓋新上市、停牌、無成交、虧損、除權息與非10元面額。
- 每個代表性樣本比對官方原表的日期、OHLC、股數、營收與 EPS；同時核對單位與口徑。
- 指標測試單調上升、下降、全平、資料不足、未知缺口、改視窗與價格修訂。
- 重複同步、部分失敗、來源欄位變更、上游429／timeout／HTML錯誤頁皆不破壞已發布資料。
- 每張圖與每個指標可追溯來源、版本、資料期間、計算口徑與有效範圍。

資料來源可行性是第一個實作關卡；對尚未驗證的來源能力不預先編寫看似可用的抓取器或填入假資料當完成。
