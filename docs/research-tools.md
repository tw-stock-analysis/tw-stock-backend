# 公開研究工具

這組功能不讀寫資料庫、不改 ORM／migration、不保存來源快照或 CSV，也沒有行情快取、自動重試或輪詢。沿用兩個既有 TWSE OpenAPI 來源，不增加其他供應商。所有路由公開，回應 `Cache-Control: no-store`。

| GET 端點 | 功能 | 每次來源請求 |
| --- | --- | --- |
| `/api/v1/research/screener` | 篩選、排序、分頁 | 日成交 `STOCK_DAY_ALL` 一次 |
| `/api/v1/research/screener/export` | 完整篩選結果 CSV | 重新取得日成交一次 |
| `/api/v1/research/compare?codes=0050,2330` | 2～4 檔成交及估值比較 | 日成交一次，再依序取得 `BWIBBU_ALL` 一次 |
| `/api/v1/research/overview` | 最新有效交易日的漲跌分布及三份前 10 名排行 | 日成交一次 |

端點明確宣告於 `app/api/v1/endpoints/research.py`，輸入與輸出位於 `app/schemas/research.py`，計算位於 `app/services/research.py`。目前共有 **55 個公開端點、5 個認證端點，合計 60 個 API 路由**，不計文件頁。

## 篩選與排序

- `q`：代碼或名稱，不分大小寫，最多 100 字。
- `min_price`／`max_price`：收盤價區間，單位為元，含端點。
- `min_change`／`max_change`：計算的漲跌百分比區間，含端點。
- `min_volume`：最低成交股數，整數，單位為股。
- `sort`：`code`（預設）、`closing_price`、`change_percent`、`trade_volume`、`trade_value`。
- `order`：`asc`（預設）或 `desc`。
- `page`：預設 1；`limit` 預設 20，最多 100。

先篩選完整的本次來源，再排序、分頁。所有數值比較使用 Decimal，保留來源的代碼前導零、大整數與小數字串。數值相同時按代碼升冪排列，缺值不論排序方向都放最後；設定該欄數值條件時排除缺值。未知參數、不合法或反向區間回 422，且不呼叫 TWSE。

漲跌幅 = 漲跌價差 ÷（收盤價 − 漲跌價差）× 100。收盤價及推算前收必須大於零，來源的非數值漲跌註記不強制轉換，無法計算時傳回 `null`。篩選與排序使用未四捨五入的計算值，顯示值以十進位四捨五入至小數 4 位；這是衍生計算，並非來源提供的盤中即時漲跌幅。

## CSV

CSV 套用相同條件與排序，忽略 `page`／`limit`，匯出完整結果。匯出時重新取得來源，所以可能與畫面先前取得的結果不同；失敗回 JSON 錯誤，不產生假成功 CSV。

使用 UTF-8 BOM、CRLF 與標準 CSV 引號跳脫。代碼前加單引號避免 Excel 丟失前導零；公式開頭及控制字元開頭的欄位也加單引號，包含負數字串。下載保留資料日期、來源數值及單位；用程式讀取時須留意這個試算表安全前綴。

## 比較與來源失敗

代碼需為 2～4 個不同的 4～6 位大寫英數代碼，以逗號分隔。依輸入順序顯示；日成交中未知的代碼 `quote=null`，缺少估值時 `valuation=null`。若全部代碼都沒有成交資料，就不再請求估值。

日成交失敗時整份查詢失敗，不保留上一輪結果。估值失敗時仍回本次新取得的成交資料，所有估值清空，另提供 `valuation_error`；成功但未提供估值則沒有此錯誤。成交與估值各有日期、取得時間及來源，不把兩份來源當成同一交易日。日成交最多 30 秒、估值最多 20 秒，依序執行，使來源等待預算低於既有 Nginx 60 秒上限。

## 市場總覽範圍

從本次成交快照找出最新有效交易日，只將相同日期的證券納入統計與排行；支援民國 7 位與西元 8 位日期。其他日期或無效日期列計入 `excluded`。漲跌依可計算的原始漲跌幅分類，不將缺值當平盤；上漲、下跌、平盤、無法分類的數量合計為 `total`。成交量榜排除缺值與非正數。

涵蓋來源中的上市證券，包含 ETF 等，不能解讀成僅普通股或官方大盤漲跌家數。前端另提供既有官方指數頁的連結。
